# Java Bank Account

A Java object-oriented banking model that demonstrates encapsulation, constructors, getters and setters, and inheritance through a basic bank account and checking account structure.

## Features

- Represents a basic bank account
- Creates checking accounts using inheritance
- Uses private attributes for encapsulation
- Uses constructors to initialize account information
- Includes getters and setters for account attributes
- Uses `super()` to initialize inherited account information
- Stores a monthly fee for checking accounts

## Class Structure

### BankAccount

The `BankAccount` class represents a basic bank account and contains:

- Account number
- Account balance
- Account owner

It includes a constructor along with accessor and mutator methods for each attribute.

### CheckingAccount

The `CheckingAccount` class extends `BankAccount` and adds:

- Monthly fee

The class demonstrates inheritance by extending `BankAccount` and using `super()` to initialize the inherited attributes.
